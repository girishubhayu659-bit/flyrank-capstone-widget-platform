Acme SaaS Blog & Marketing Site

This is an external customer website hosted on a separate origin from the FlyRank Widget API (http://localhost:8000). It demonstrates that your widget can be embedded on any arbitrary website on the internet using a single line of script.

Embed Code Pasted by Customer:

<script src="http://localhost:8000/widget.js?id=demo-widget-newsletter"></script>

Notice the lead capture widget rendered in the bottom-right corner! Submitting this form tests:

  • Cross-Origin Resource Sharing (CORS preflight & POST headers)
  • Client-side honeypot protection
  • Dynamic schema rendering and boundary validation
  • IP Geolocation enrichment with dual-provider fallback
  • Safe side-effect notification triggers
